# Refactoring-Pratices

## Liga da Refatoração (Turma: Engenharia de Software II 2026.4 | UFPA | Prof. Dr. Victor Santiago)

Este projeto contém **10 questões**,cada uma em um pacote separado.Em cada questão aplica-se uma técnica de refatoração.

### Estrutura

1. Produção: `src/main/java/br/ufpa/refactoring/qX/`

2. Testes: `src/test/java/br/ufpa`

### Técnicas Aplicadas

1. Extract Method
2. Inline Method
3. Replace Temp with Query
4. Replace Inheritance with Delegation
5. Collapse Hierarchy
6. Replace Conditional with Polymorphism
7. Introduce Null Object
8. Extract Class
9. Move Method / Move Field
10. Introduce Parameter Object

A ordem das técnicas é igual a ordem dos arquivos de `src/main`.
